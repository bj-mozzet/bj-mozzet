### 👋 About

매일 많은 사람이 쓰는 모바일 서비스의 **서버를 만들고, 지키고, 더 빠르게** 하는 일을 합니다.

- 🛠 **API & 서비스 로직** — 오래된 코드도 안전하게 고쳐 나가는 레거시 개선
- 🔁 **배치 & 데이터 파이프라인** — 매일 도는 작업을 더 짧고 예측 가능하게
- ☁️ **클라우드 운영** — 비용, 성능, 안정성 사이의 균형 잡기
- 🤖 **AI 활용** — LLM 기반 기능 개발, AI 에이전트와 함께 일하는 개발 흐름 만들기
